# Interactive Developer Portfolio 🚀

A highly immersive, cyberpunk-inspired developer portfolio built with **Next.js**, **React**, **Three.js**, and **Framer Motion**. This portfolio acts as a "Creative Engineering Monitor," showcasing full-stack projects, a real-time signal grid of skills, and an interactive 3D environment.

🌐 **Live Demo:** [https://main.dw5hoa6sugvel.amplifyapp.com/](https://main.dw5hoa6sugvel.amplifyapp.com/)

---

## ✨ Features

- **Retro-Futuristic UI:** A design system built from scratch using raw CSS, featuring glassmorphism, CRT terminal emulation, glowing accents, and high-tech typography.
- **Interactive 3D Elements:** An integrated WebGL canvas using Three.js/React Three Fiber with floating geometries.
- **The Signal Grid (Skills Map):** A custom SVG node graph that maps out backend, frontend, cloud, and ML skills with animated, pulsating signal paths.
- **Terminal Project Monitor:** A unique carousel built to resemble a retro CRT monitor, complete with scanlines, glare, and flicker effects.
- **Scroll-Linked Animations:** Intersection Observers trigger "binary decoding" effects on headings as you scroll down the page.
- **Responsive Design:** Fully fluid CSS Grid and Flexbox layouts ensuring perfect usability on mobile devices and large desktop displays.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **UI Library:** React.js
- **Animations:** Framer Motion
- **3D Graphics:** Three.js / React Three Fiber (`@react-three/fiber`, `@react-three/drei`)
- **Icons:** Lucide React
- **Hosting / CI/CD:** AWS Amplify

## 🚀 Running Locally

If you'd like to run this project locally on your machine:

### 1. Clone the repository
```bash
git clone https://github.com/SachinYadav2446/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```

### 4. View in Browser
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Deployment

This project is configured for continuous deployment on **AWS Amplify**.
Pushing to the `main` branch automatically triggers a build and deploys the latest version using the `amplify.yml` configuration.
